# Data Science Assignments

A collection of Jupyter notebooks and coursework exploring data science, statistics, and machine learning using Python.

## Topics

- Python, NumPy, and Pandas
- Statistics, hypothesis testing, and data transformation
- Exploratory data analysis (EDA)
- Regression, clustering, and classification
- Decision trees, random forests, gradient boosting, and SVM
- PCA, neural networks, NLP, and recommendation systems
- RNNs and time-series analysis

## Using the notebooks

Open a notebook in Jupyter Notebook, JupyterLab, or Google Colab. Check each notebook for its required libraries and datasets; some datasets may not be included in this repository.

These materials are coursework and learning assignments.
